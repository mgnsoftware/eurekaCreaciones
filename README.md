# Eureka Creaciones

Sitio estático en español para Eureka Creaciones. Para verlo localmente, abre `index.html` en el navegador. No requiere instalación ni compilación.

## GitHub Pages

Sube estos archivos a la raíz de la rama `main` de un repositorio llamado `eurekaCreaciones`. En **Settings → Pages**, elige **Deploy from a branch**, rama **main**, carpeta **/ (root)** y guarda.

El formulario arma un mensaje para WhatsApp con el nombre, correo, teléfono y asunto. El visitante confirma el envío en WhatsApp. Las imágenes de la galería son conceptos ilustrativos generados para el sitio.


## Rastreo e indexación

El sitemap contiene la URL canónica de la portada. Registra la propiedad de prefijo https://mgnsoftware.github.io/eurekaCreaciones/ en Google Search Console y Bing Webmaster Tools para enviar el sitemap y consultar el estado de indexación.

El robots.txt de este proyecto se publica bajo /eurekaCreaciones/. Los rastreadores consultan el robots.txt de la raíz del dominio. Para anunciar el sitemap desde ese archivo, agrega la directiva Sitemap a https://mgnsoftware.github.io/robots.txt si administras ese sitio, conservando sus reglas existentes.
